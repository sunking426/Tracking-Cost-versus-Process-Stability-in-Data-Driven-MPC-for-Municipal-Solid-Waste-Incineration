# Tracking Cost versus Process Stability in Data-Driven MPC for Municipal Solid Waste Incineration

Source code for the accompanying study. The controller uses a Ridge increment
model, cross-entropy planning and a historical state–action support filter.

## Source package

The source archive in this repository contains the implementation, frozen
experiment configurations, dependency lists, tests and reproduction documentation.
Extract it into a local directory before running the commands in its README.
`SHA256SUMS.txt` contains the archive checksum.

Raw data, flame images, model checkpoints, archived trajectories, the manuscript
and supplementary paper files have not been uploaded. Running the experiments
requires the matching local data assets. No data release is currently available.

## Environment

The recorded environment is Python 3.10.8 on macOS ARM64 with CPU computation.
Linux is supported; Windows users should use WSL. The extracted package includes
`requirements.txt`, `requirements-lock.txt`, an English README and a Chinese README.
