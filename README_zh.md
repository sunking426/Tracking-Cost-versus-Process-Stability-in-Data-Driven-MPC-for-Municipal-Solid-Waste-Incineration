# 垃圾焚烧过程跟踪成本与稳定性：数据驱动MPC

本仓库对应论文《Tracking Cost versus Process Stability in Data-Driven MPC for Municipal Solid Waste Incineration》。

## 源码

仓库中的源码ZIP包含完整实现、冻结配置、依赖清单、测试及复现说明。请先解压到本地目录，再按照包内README运行。校验值见`SHA256SUMS.txt`。

原始数据、火焰图像、模型权重、归档轨迹、论文及补充材料均暂未上传。执行实验需要另备配套本地数据，当前没有数据Release。

原实验环境为Python 3.10.8、macOS ARM64、CPU。Linux可按包内说明配置，Windows请使用WSL。
